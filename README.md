# FocusFlow — Student Productivity Dashboard

A beginner-friendly frontend project built with HTML, CSS, vanilla JavaScript, and browser localStorage.

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No installation, backend, or internet connection is required.

## Features
- Add, edit, delete, and complete tasks
- Track task counts and completion percentage
- Set a subject, priority, and due date
- Filter tasks by all, pending, or completed
- Show upcoming deadlines and overdue counts
- Save tasks in the browser using localStorage
- Responsive layout for desktop and mobile

## Technology explanation
- HTML structures the dashboard, forms, buttons, and task areas.
- CSS styles the cards, sidebar, colors, and responsive layout.
- JavaScript handles user events, task data, filtering, date calculations, and rendering.
- localStorage stores the task array in the current browser.

## Important scope note
This is a frontend-only demo. It has no server, shared database, login, or cloud synchronization. The starter tasks are sample data. Data is saved in the browser where the project is opened.

## Demo flow
1. Point out the four summary cards.
2. Add a task with a title, category, priority, and due date.
3. Edit the task and change its priority.
4. Mark it completed and show the statistics update.
5. Use the filters.
6. Refresh the browser to show saved data.
7. Delete a sample task if needed.
